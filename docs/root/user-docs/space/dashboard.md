# Dashboard

The fleet's operations dashboard — health, throughput, deploys, and live events, all on one
screen.

**Permission level:** Admin portal access. (Reached via **Admin → Dashboard**; filed here
under Space in this guide by choice, not because the app itself puts it here.)

## Where it lives

**Admin → Dashboard**.

## What you see

- **Header tiles** — total devices, online now, offline, installations (in the selected time
  range), updating now, and update errors
- **Download throughput** — an area chart (MB/min) with current/peak/average, over a
  selectable time range (1h through last year)
- **Fleet health** — a donut of online / offline / error devices
- **Deploy success rate** — a sparkline plus the current success percentage
- **Software state** — a bar split into up to date / pending update / error / unknown
- **Top installed** — the catalog's most-installed apps, with version and status
- **Live events** — a streaming feed of recent alerts, with a link to the full Events log
- **Recent activity** — the latest delivery/deploy activity, with a link to the full Activity
  feed

## What you can do

Change the time range (top right) — it re-scopes the throughput chart, deploy success rate,
and installation count together.
