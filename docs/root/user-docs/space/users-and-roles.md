# Users & Roles

Manage who has an account on this deployment and which platform-wide group each one belongs
to.

**Permission level:** Admin portal access, `manage-users` to actually invite or change anyone.
(Reached via **Admin → Users & Roles**; filed here under Space in this guide by choice.)

## Where it lives

**Admin → Users & Roles**.

## What you see

Every user: avatar, name, email, the groups they belong to, and status
(**Active** / **Pending** / **Suspended**). Search by name/email, filter by group.

## Groups

Five platform-wide groups, independent of the per-project roles in
[Project Detail's Members tab](../developer/project/project-detail#members):

- **user** · **viewer** · **tech** · **contributor** · **system-administrator**

## What you can do

- **Invite user** — email, username, optional first/last name, and which group(s) to assign
  up front
- **Change permissions** on any existing user — add or remove groups
