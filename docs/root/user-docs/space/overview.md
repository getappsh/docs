# Space — Overview

The **Store** portal — where any signed-in user browses, installs, and manages apps on their
own devices. Unlike Admin and Developer, it needs no special role: every user gets it.

**Permission level:** Any signed-in user

## Where it lives

The portal switcher at the top of the sidebar — **Store**.

- [Workspace](./workspace) — the Store portal's own landing tab
- [Settings](./space-settings) — *coming soon*

Three more pages are grouped here too — [Dashboard](./space-dashboard), [Users & Roles](./users-and-roles),
and [Pending](./pending) — but note they're **Admin portal** pages reached from Admin's own
nav, not the Store portal above. They're filed under Space in this guide as a deliberate
organizational choice.

## How it relates to Admin and Developer

Store shows the same underlying [projects and releases](../developer/developer-overview) Developer
authors and Admin distributes — just from the installing user's own point of view. A
`released` version is what a user can install; draft and in-review releases don't show up
here.
