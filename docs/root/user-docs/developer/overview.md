# Developer — Overview

The Developer portal is where the things Admin later deploys actually get authored: projects
and their releases.

**Permission level:** Developer portal access. Creating projects needs project-create
permission specifically; browsing every project's releases (not just your own) needs the
`list-releases` permission.
