# My Projects

Your project workspace — every [project](./project-overview) you have access to, active or archived.

**Permission level:** Developer portal access

## Where it lives

**Develop → My Projects**.

## What you see

- **Grid** or **list** view of every project you can see, each with its type, and a live
  count of pinned projects in the sidebar
- **Search** by name or description
- **Show archived** to bring archived projects back into view

![My Projects grid view — 60 real pinned projects as cards, each with its version, description, release count, and member count](/img/manual/project/my-projects-grid.png)

![My Projects list view — the same 60 projects as a table, with type, version, releases, and members columns](/img/manual/project/my-projects-list.png)

## What you can do

- **New project** (needs project-create permission) — see [New Project](./new-project)
- Open a project to its [Project Detail](./project-detail) page
- **Pin** a project — pinned projects get their own shortcut section in the sidebar
- **Archive** a project — hides it from the default list without deleting it;
  **Restore** brings it back
- **Permanently delete** an archived project — irreversible
