# My Releases

Every release across every project you have visibility into, in one table.

**Permission level:** The `list-releases` permission (without it, this nav entry doesn't
appear — you still see your own projects' releases under [Project Detail](../project/project-detail))

## Where it lives

**Develop → All Releases** in the nav (the page itself is your release list — see the note
below).

## What you see

One row per project: its type, latest version, total release count, latest release's status
(**Published** / **Draft** / **Archived**), and when it was last released.

## What you can do

- **Filter** by project name
- Click a row to open that project's [Project Detail](../project/project-detail)

:::note Nav label
The sidebar calls this **All Releases** — the `list-releases` permission it's gated on can
surface releases beyond your own projects, so what you see here may be broader than "mine"
depending on your role.
:::
