# Tier 1 – AppStore Agent (Field)

:::info Who is this for?
This guide is for **Tier 1** agents — the first line of support. Follow the
interactive decision trees by issue type. If the issue is not resolved,
escalate to Tier 2 / Desk with a summary of the steps you took.

> 💡 Each decision tree has an **English / עברית** toggle in the corner (English
> by default), plus **Back** / **Start over** controls.
:::

## The Agent AppStore

The issues below are reported from the **Agent AppStore** on the device. Each
application card shows its status and a download / retry control.

<p align="center">
  <img src="/img/agent-store-overview.png" width="720" alt="Agent AppStore — application grid with download and retry controls" />
</p>

When a download fails, the card shows a red **Download Failed** label and a
retry button **↺**. Hovering the failed card reveals the exact error message —
collect it before escalating.

## 3. Before Escalating — What to Collect

:::warning Don't escalate empty-handed
Collect all of the following before contacting Tier 2 or Desk.
:::

| # | Question | Where to Find It |
|---|----------|------------------|
| 1 | What is the OS? (Windows / Linux) | Ask the agent directly |
| 2 | What is the DeviceType? (Agent / Other) | GetApp interface → Device details |
| 3 | Did "Download Failed" + retry button ↺ appear? | Screenshot from the agent |
| 4 | What is the error message? | Hover over the failing card → read the tooltip |
| 5 | Is there an active internet connection? | Check the network icon — ↓ ↑ Mbps |

**Escalation Template**

```text
Escalation to Tier 2 / Desk
============================
Issue: [ Cannot see release / Download failed / Other ]
Connection type: [ Removable media / Cellular ]
OS: [ Windows / Linux ]
DeviceType:
Error message:
"Download Failed" + retry button ↺ visible: [ Yes / No ]
Internet connection available: [ Yes / No ]
Steps performed:
  1.
  2.
  3.
```
