# Offering Commands

Query available offerings.

## `offering device-type <TYPE>`

List offerings for a device type.

```bash
getapp offering device-type router --platform linux
```

## `offering platform <PLATFORM>`

List offerings for a platform.

```bash
getapp offering platform windows
```

## `offering project <PROJECT>`

List offerings for a project.

```bash
getapp offering project my-project
```

Use `--help` with any command for full details.
