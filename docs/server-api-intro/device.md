# Server API — Device

The device-facing subset of the server API — delivery, deploy, device, reactive, get-map,
login, offering, rules, and diagnostics endpoints. This is the surface the GetApp Agent
itself talks to, so it's the reference to use when integrating a device or debugging
agent ↔ server calls.
