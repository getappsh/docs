# Server API — V2

The curated, resource-grouped surface — endpoints organized by resource (Users, Platforms,
Projects, Rules, Types, Groups, GetConfig, ...) rather than by controller, with only
endpoints that have a matching curation rule shown. Once live, this will be the
recommended starting point for integrating against the server.
